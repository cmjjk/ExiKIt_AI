# ExitKit AI — MVP

Локальный AI-агент для подготовки Handover Package при передаче дел.

## Возможности
- Загрузка TXT, MD, PDF (текстовых) и DOCX
- Анализ через локальный Ollama
- Выделение проектов, задач, рисков, контактов, вопросов
- JSON-просмотр и экспорт Markdown

## Запуск
1. Установите Python 3.11+ и [Ollama](https://ollama.com/).
2. Загрузите модель:

   ```bash
   ollama pull qwen2.5:3b
   ```

3. Создайте окружение и поставьте зависимости:

   ```bash
   python -m venv .venv
   # Linux/macOS: source .venv/bin/activate
   # Windows PowerShell: .venv\\Scripts\\Activate.ps1
   pip install -r requirements.txt
   ```

4. Убедитесь, что Ollama запущен. Если он не работает как служба, запустите `ollama serve` в отдельном терминале.
5. Запустите UI:

   ```bash
   streamlit run app.py
   ```

6. Загрузите `sample_data/handover_example.txt` и нажмите «Создать Handover Package».

Адрес интерфейса обычно `http://localhost:8501`.

## Переменные окружения
- `OLLAMA_MODEL` — имя модели (по умолчанию `qwen2.5:3b`)
- `OLLAMA_URL` — адрес Ollama (по умолчанию `http://localhost:11434`)

## Ограничения MVP
- OCR нет: сканы PDF не читаются.
- Для скорости обрабатываются только первые 24 000 символов объединённых документов.
- Возможны неточности LLM: проверяйте результат перед использованием.
- Исходные файлы находятся в памяти приложения; не выкладывайте реальные конфиденциальные документы в публичное облако.
- Нет аккаунтов, постоянного хранилища или интеграций.

## v2: Уточняющие вопросы и PDF

После анализа документа в интерфейсе появятся вопросы о недостающих сроках,
ответственных и следующих шагах. Введите ответы и нажмите «Добавить ответы в отчёт».
Скачайте PDF либо Markdown. Для PDF используется кириллический шрифт,
установленный в вашей операционной системе (Arial на macOS).

Для обновления из предыдущей версии: скопируйте `app.py`, `reporting.py`,
`requirements.txt` в папку проекта, затем выполните `pip install -r requirements.txt`
и перезапустите Streamlit.


## v3: подробная передача дел

- Длинные документы обрабатываются **последовательно частями по ~8500 символов** без тихого обрезания первых 24 000 символов. Лимит отдельного файла 400 000 символов, превышение явно показывается пользователю.
- Все материалы проходят через локальный Ollama; на Mac 8 ГБ большие пакеты могут обрабатываться значительно дольше.
- Расширенные разделы: предыстория и смысл проектов, принятые решения, конкретные действия, инструкции, договорённости, последствия рисков.
- При объединении результатов могут встретиться похожие факты: обязательно проверьте итоговый PDF перед использованием.
- Сканированные PDF без текстового слоя не распознаются; изображения/диаграммы и вложенные файлы пока не анализируются.
- Локальная модель 1.5B может пропускать детали и неточно пересказывать: для ответственной передачи дел нужна проверка человеком.
- Во избежание потерь детальных сведений рекомендуем разбивать очень большой комплект материалов по логическим разделам.
