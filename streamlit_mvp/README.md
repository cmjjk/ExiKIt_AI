# ExitKit AI

Локальное приложение для подготовки пакета передачи дел из рабочих документов.

## Запуск

1. Установите Python 3.11+ и Ollama.
2. Загрузите модель: `ollama pull qwen3:0.6b`.
3. Установите зависимости в виртуальное окружение:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. Запустите Ollama, если он ещё не работает: `ollama serve`.
5. Запустите интерфейс: `streamlit run app.py`.
6. Откройте `http://localhost:8501` и загрузите `sample_data/handover_example.txt`.

Используемая модель задаётся через `OLLAMA_MODEL`; адрес локального сервера — через `OLLAMA_URL`.
Например: `OLLAMA_MODEL=qwen2.5:1.5b streamlit run app.py`.

По умолчанию используется компактная `qwen3:0.6b` для сервера с 2 ГБ ОЗУ.
Для неё отключён режим рассуждений и ограничен контекст до 3072 токенов.
Это снижает расход памяти, но не гарантирует работу на любом сервере с 2 ГБ ОЗУ.
Приоритет — локальная обработка; маленькая модель может пропускать детали,
поэтому проверяйте отчёт по исходным документам.

## Как устроен анализ

- TXT, MD, текстовые PDF и DOCX обрабатываются частями до 3000 символов.
- Модель получает JSON Schema, а приложение проверяет типы ответа. При пустом извлечении появляется ошибка вместо пустого отчёта.
- Описания для отчёта запрашиваются на русском. Если модель дважды отвечает английским текстом, приложение сообщает об ошибке вместо выдачи английского отчёта.
- Имя файла-источника назначает приложение. Совпавшие записи из разных частей объединяются; противоречия помечаются для проверки.
- Отчёт короткий: текущее состояние, ближайшие действия, риски и вопросы для уточнения. Подробные извлечённые данные остаются в отдельной вкладке интерфейса.
- После анализа можно уточнить ответственных, сроки и следующие шаги, а затем скачать PDF или Markdown. Для срока используется поле даты с календарём. Отдельных вопросов о числах в текущей версии нет; для них подготовлен числовой тип поля.
- Последний запрос к модели выгружает её из памяти Ollama. Во время анализа GPU всё равно может нагреваться.

## Ограничения

- Один файл: до 10 МБ и до 60 000 извлечённых символов. Один запуск: до 20 частей. Если лимит превышен, приложение сообщает об этом; данные не обрезаются молча.
- OCR для сканов PDF нет. Таблицы DOCX читаются как текст; изображения не анализируются.
- Даже при строгой JSON-схеме маленькая модель может упустить факт или ошибиться. Проверяйте пакет по исходным документам.
- Документы живут в памяти приложения в течение сессии. Используйте локальный Ollama для конфиденциальных материалов.
