# ExitKit AI

Open-source AI-агент для передачи знаний и дел при увольнении или смене роли. Принимает заметки и документы сотрудника (`.txt`, `.md`, `.pdf`, `.docx`) и собирает **Handover Package**: проекты, задачи, риски, контакты, инструкции, договорённости, открытые вопросы. Анализ идёт через локальный [Ollama](https://ollama.com), данные не уходят во внешние сервисы.

## Быстрый старт

1. Установите [Ollama](https://ollama.com/download) и запустите её.
2. Выполните:

```bash
./run.sh
```

Скрипт скачает модель (`qwen2.5:3b`, ~2 ГБ), создаст `.venv`, поставит зависимости и откроет http://localhost:8501.

Вручную:

```bash
ollama pull qwen2.5:3b
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Как пользоваться

1. Загрузите файлы или вставьте заметки (пример: `examples/sample_notes.txt`).
2. Нажмите «Создать Handover Package».
3. Ответьте на уточняющие вопросы о недостающих ответственных, сроках и шагах — отчёт обновится.
4. Скачайте PDF или Markdown.

## Настройка

| Переменная | По умолчанию |
|---|---|
| `OLLAMA_MODEL` | `qwen2.5:3b` (для лучшего качества — `qwen2.5:7b`) |
| `OLLAMA_URL` | `http://localhost:11434` |

## Структура

- `app.py` — интерфейс Streamlit
- `core.py` — чтение файлов, разбиение на части, вызов Ollama, объединение
- `reporting.py` — отчёт, уточняющие вопросы, PDF и Markdown
- `tests/` — тесты (`pytest`)
- `examples/` — пример входных данных

## Ограничения

- Нет OCR: сканы PDF не читаются.
- Длинные документы обрабатываются по частям (~8500 символов), это медленно на слабых машинах.
- Маленькие модели могут пропускать детали: результат нужно проверять человеком.
- Для PDF нужен системный шрифт с кириллицей (Arial на macOS, DejaVu на Linux).
